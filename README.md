# 🛡️ Sentraa AI — Official Front Page

> Real-Time AI Agent Security & Runtime Governance Platform — inspired by [zenity.io](https://zenity.io)

Sentraa AI intercepts, evaluates, and steers every AI agent action in real time **before** it executes. Unlike passive logging tools that alert after the damage is done, Sentraa blocks prompt injections, over-shared data access, and rogue autonomous tool calls at the gate.

---

## 🚀 Live Demo & Development

### 1. Install dependencies:
```bash
npm install
```

### 2. Start development server:
```bash
npm run dev
```

### 3. Production Build:
```bash
npm run build
npm run preview
```

## 🎨 Design & Architecture Highlights (Modeled after Zenity.io)

- **Dark-Mode Enterprise Cybersecurity Aesthetic**: Violet / indigo / cyber accents with glowing borders, radial mesh lighting, and grid backdrop.
- **Interactive Live Agent Bouncer (`LiveAgentBouncer.tsx`)**: Real-time simulation of the 4-tier interception pipeline (Allowlist → Pattern Signatures → NER PII Masking → Semantic Risk) running at sub-15ms inline latency.
- **The Threat Paradox (`DecisionParadox.tsx`)**: "By the Time Anyone Notices, the Agent Already Decided" — External Injection, Internal Over-Exposure, and Autonomous Drift.
- **The Three Pillars (`PlatformPillars.tsx`)**: Surface, Enforce, Protect with live screenshot tabs from the Sentraa AI production dashboard.
- **Context vs Intent (`ContextVsIntent.tsx`)**: Detailed breakdown explaining why legacy DSPM, IAM, EDR, and AI proxies fall short for autonomous agents, complete with an architectural capability matrix.
- **Interactive Policy Studio (`PolicyPlayground.tsx`)**: Visitors can toggle live guardrails and test custom prompt/tool injections.
- **Proven Impact & Scale (`MetricsSection.tsx`)**: <15ms latency, 99.8% unauthorized action reduction, 150K+ daily actions, and verified enterprise testimonials.
- **AI Security Assessment Hub (`RiskModal.tsx`)**: Interactive 4-step wizard calculating real-time enterprise AI posture scores and recommended Sentraa guardrail policies.
- **Sentraa Labs Intelligence (`ResearchSection.tsx`)**: Threat advisories, AgentFlayer vulnerability disclosures, and Model Context Protocol (MCP) tool security reports.
- **Enterprise Multi-Column Navigation & Footer**: Deep navigation with links to npm SDK (`@sentra-ai/sdk`), live dashboard (`sentraatech.info`), and regulatory frameworks (GDPR, DPDP, HIPAA, PCI-DSS, NIST AI RMF).
